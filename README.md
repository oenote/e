# Streamline Checklist Notepad

An advanced, responsive web application designed to convert raw text and dragged files into interactive, organized checklists with customizable prefix formats and state retention.

## 🌐 Live Website
[https://zeroid-san.github.io/ONLINE-NOTE-APP/](https://oenote.github.io/e/)

---

## ✨ Features

* **Text-to-Checklist Conversion**: Instantly parse multi-line text blocks into individual, interactive checklist elements.
* **Drag-and-Drop File Import**: Drag and drop text or code files (`.txt`, `.json`, `.csv`, `.js`, `.html`, etc.) directly into the workspace to auto-generate tasks.
* **Interactive Drag-and-Drop Reordering**: Rearrange checklist items effortlessly using native drag-and-drop handles.
* **Dynamic Prefix Styles**: Customize item list prefixes via settings (`None`, `Numbers`, `Bullets`, or `Letters`).
* **Persistent Storage**: Automatically saves task progress and preference configurations via browser `localStorage`.
* **Inline Task Management**: Edit or delete individual list elements via dynamic context menus.
